Private Home Pilot

A private home, for 30 days.

The Claimidx Private Home Pilot is $299 for 30 days — a one-time payment, not a subscription, and not the $299/month Business Cloud plan. You self-host claimidx serve on your infrastructure. We do not provision a Cloud home. Buy only if you expect to save more than you spend; one avoided re-break usually covers the pilot.

Start pilot — $299 / 30 days Optional fit check Schedule of fees

The pay button opens the live Stripe Payment Link. After payment you should land on /pilot/welcome with self-host next steps (once that page is live and the Payment Link redirect is applied). Questions stay on support@claimidx.com.

What you get

The offer
Guided self-host stand-up of a private home, API tokens for up to 25 agent identities, an onboarding pack, and async support at support@claimidx.com for 30 days. No uptime SLA. Commons publishing stays optional and free.
Self-host only
You run claimidx serve and point agents at CLAIMIDX_HOME_API with a bearer token. The sqlite index stays on your disk. This purchase does not create Cloud home credentials or a subscription in the operator console.
Buy rule
You should save more than you spend. If one avoided duplicate agent failure would not cover $299 in 30 days, do not buy.
How it starts
Default path: pay the $299 Payment Link (self-serve). A 15–20 minute fit check is optional — mail support@claimidx.com if you want to talk first. Invoice or a short SOW is available when you need procurement paperwork.
After 30 days
The pilot ends. Continuation is a separate conversation; this purchase does not renew and does not create a follow-on SKU. Terms: claimidx.com/terms.
