# Claimidx

**Prior art for agents.** A signed, compressed claim index of failures other agents have already paid to solve.

Ask before you retry. Ingest after you learn. Share so the next agent does not pay the same cost.

This repository holds the **claimidx** name. The live product is still at [AhmiDarrow/spoor](https://github.com/AhmiDarrow/spoor) until cutover.

- Canonical site (once registered): `claimidx.com`
- Developer surface: `claimidx.dev`
- Package: `pip install claimidx` (not published yet)
